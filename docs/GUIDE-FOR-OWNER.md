# راهنمای ساده — برای کسی که برنامه‌نویس نیست

> این فایل برای **مالک سایت** یا **مدیر محتوا** نوشته شده.  
> قرار نیست کد بزنی. فقط بفهمی سیستم چیه و کجا چیکار کنی.

---

## این سایت اصلاً چیه؟

سایت **راهبر حساب** یک پلتفرم کامله که این کارها رو با هم انجام می‌ده:

- **سایت عمومی** — صفحاتی که مردم می‌بینن (دوره‌ها، بلاگ، درباره ما، ...)
- **پنل مدیریت** — جایی که تو محتوا رو عوض می‌کنی (`/admin`)
- **پنل کاربر** — جایی که دانشجو بعد از خرید دوره می‌ره (`/panel`)
- **فروشگاه** — سبد خرید و پرداخت آنلاین

اگه قبلاً **وردپرس** دیده باشی، ذهنیتش شبیه همونه: قالب، افزونه، صفحه‌ساز، بلاگ. فقط ظاهر پنل و جزئیات فرق داره.

---

## سه جای مختلف — گیج نشو

| جا | آدرس | کی می‌ره؟ |
|----|------|-----------|
| **سایت** | `rahbarhesab.com` | همه بازدیدکننده‌ها |
| **پنل مدیریت** | `rahbarhesab.com/admin` | تو و تیم محتوا |
| **پنل کاربر** | `rahbarhesab.com/panel` | کسی که خرید کرده یا ثبت‌نام کرده |

**ورود به پنل مدیریت:** ایمیل + رمز عبور (همون که برنامه‌نویس بهت داده).

**ورود کاربران عادی:** فقط با **شماره موبایل** و **کد پیامکی** — رمز عبور ندارن.

---

## توی پنل مدیریت چی داری؟

### صفحات
صفحات ثابت مثل «درباره ما»، «تماس»، یا هر صفحه جدید.

- **لیست صفحات:** `/admin/pages`
- **صفحه‌ساز:** وقتی روی یک صفحه می‌زنی «صفحه‌ساز» — با بلوک‌ها صفحه رو می‌چینی (مثل Elementor ساده)

### صفحه‌ساز — چطور کار می‌کنه؟

فکر کن داری یک پازل می‌چینی:

1. از سمت چپ **بلوک** انتخاب می‌کنی (مثلاً Hero، متن، تصویر، سوالات متداول)
2. تنظیماتش رو پر می‌کنی (عنوان، متن، عکس، ...)
3. **پیش‌نمایش** می‌زنی ببینی چطور می‌شه
4. **ذخیره** می‌کنی

**بلوک «چیدمان ستونی»** — برای layout پیچیده‌تر:

```
یک ردیف ستون
  ├── ستون ۱
  │     ├── قسمت ۱ → می‌تونی چند بلوک بذاری
  │     ├── قسمت ۲
  │     ├── قسمت ۳
  │     └── قسمت ۴
  ├── ستون ۲
  │     └── ...
  └── [دکمه افزودن ستون]
```

هر ستون **۴ قسمت** داره. توی هر قسمت می‌تونی **یک یا چند بلوک** (متن، عکس، دکمه، ...) بذاری.

### بلاگ
نوشته‌های سایت — `/admin/posts`

### دوره‌ها
مدیریت دوره‌های آموزشی — `/admin/courses`  
(فصل، درس، ویدیو، قیمت)

### سفارش‌ها
کی چی خریده — `/admin/orders`

### منوها
لینک‌های بالای سایت — `/admin/menus`

### تنظیمات
لوگو، عنوان سایت، اطلاعات تماس — `/admin/settings`

### رسانه
آپلود عکس و فایل — `/admin/media`

## کاربر سایت چه مسیری می‌ره؟

```
۱. سایت رو می‌بینه
۲. دوره رو انتخاب می‌کنه
۳. «افزودن به سبد» یا «ثبت‌نام رایگان»
۴. اگه پولی باشه → پرداخت آنلاین (زیبال)
۵. با موبایل لاگین می‌کنه (کد SMS)
۶. می‌ره پنل کاربر → دوره‌های من
۷. درس‌ها رو می‌بینه و پیشرفتش ذخیره می‌شه
```

## چی رو خودت می‌تونی؟ چی رو باید برنامه‌نویس انجام بده؟

### خودت (بدون کد)

| کار | کجا |
|-----|-----|
| نوشتن/ویرایش صفحات | صفحه‌ساز |
| نوشتن بلاگ | `/admin/posts` |
| اضافه کردن دوره و درس | `/admin/courses` |
| دیدن سفارش‌ها | `/admin/orders` |
| عوض کردن لوگو | `/admin/settings` |
| چیدن منوی سایت | `/admin/menus` |
| آپلود عکس | `/admin/media` |

### برنامه‌نویس

| کار | چرا |
|-----|-----|
| نصب اولیه سرور | نیاز به دستور و تنظیمات فنی |
| اتصال درگاه پرداخت | مرچنت کد و API |
| اتصال SMS (IPPanel) | API key |
| بلوک جدید صفحه‌ساز | کد PHP |
| قالب/طراحی جدید | فایل‌های قالب |
| افزونه خاص | کد |
| رفع باگ | — |

## واژه‌های ساده

| واژه | یعنی چی؟ |
|------|----------|
| **بلوک** | یک قطعه صفحه (مثلاً یک بنر، یک پارagraph، یک FAQ) |
| **صفحه‌ساز** | ابزار چیدن بلوک‌ها |
| **قالب (Theme)** | ظاهر کلی سایت — رنگ، فونت، layout |
| **افزونه (Plugin)** | قابلیت اضافه بدون دست زدن به هسته |
| **Seeder** | داده اولیه — وقتی سایت تازه نصب می‌شه |
| **Deploy** | بردن تغییرات روی سرور واقعی |
| **OTP** | همون کد ۶ رقمی SMS |
| **LMS** | سیستم مدیریت یادگیری — دوره، درس، پیشرفت |

## اگه مشکلی پیش اومد

| مشکل | اول چک کن | بعد |
|------|-----------|-----|
| صفحه ذخیره نمی‌شه | اینترنت، دوباره login | برنامه‌نویس |
| SMS نمی‌اد | شماره درسته؟ | برنامه‌نویس (IPPanel) |
| بعد پرداخت دوره نیومد | چند دقیقه صبر | برنامه‌نویس |
| عکس لود نمی‌شه | آدرس درسته؟ از رسانه آپلود کن | — |
| سایت down | — | برنامه‌نویس / هاست |

## خلاصه یک خطی

**سایت = محتوا (صفحات + بلاگ + دوره) + فروش + ورود با موبایل.**  
**تو محتوا و دوره رو مدیریت می‌کنی. برنامه‌نویس زیرساخت و کد سفارشی.**

اگه جایی گیر کردی، `HANDBOOK-DEVELOPER.md` رو بده برنامه‌نویس — اونجا همه چیز از route تا دیتابیس توضیح داده شده.
